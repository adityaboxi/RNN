# Recurrent Neural Network (RNN) with Keras

A clean, minimal implementation of a Recurrent Neural Network using TensorFlow and Keras, built for learning sequential data modeling from first principles.

## Model Architecture

The script sets up a sequential model with a recurrent layer and a dense output layer:
* **`SimpleRNN`**: Processes sequences with 4 time steps and 5 features per step, mapping them to 3 hidden units.
* **`Dense`**: A single output neuron with a sigmoid activation function for binary classification or probability output.
